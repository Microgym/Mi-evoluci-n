# Mi Evolución v18 — Editor completo de rutinas

Mejoras:
- Crear rutinas desde la app.
- Catálogo visual ampliado por zona muscular.
- Buscar por nombre, músculo o equipo.
- Editar una rutina ya guardada.
- Cambiar series, repeticiones y máquina/equipo.
- Reordenar ejercicios con Subir/Bajar.
- Eliminar ejercicios.
- Duplicar una rutina.
- Eliminar una rutina completa.
- Sesión 18 sigue incluida y ahora también se puede editar.
- Al ejecutar una rutina, las series siguen siendo editables individualmente (kg/reps, añadir/eliminar).

El catálogo continúa siendo local/offline y utiliza iconos identificativos. Una versión posterior puede incorporar ilustraciones específicas de cada movimiento/máquina.
