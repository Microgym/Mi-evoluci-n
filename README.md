# Micro Health v22.3.24 — Exportar informe de músculos y pesos a PDF

En el resumen de entrenamiento con mapa muscular y kilos movidos aparece el botón **📄 Exportar PDF**. Abre un documento listo para imprimir o guardar como PDF desde el navegador y compartirlo desde el iPhone. Incluye fecha, gimnasio si consta, estadísticas, kilos por músculo, mapa anatómico y detalle por ejercicio. No cambia ningún registro.

En iPhone, toca Exportar PDF y luego «Guardar o compartir como PDF» para abrir las opciones de impresión/compartir de iOS. Si el navegador bloquea ventanas emergentes, permite abrir la nueva pestaña.

Se conserva la clave `miguel-evolucion-v4` y los datos locales. Antes de actualizar, exporta JSON; las fotos de IndexedDB requieren respaldo aparte.
