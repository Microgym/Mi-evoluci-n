MicroHealth v22.3.147 — Hora manual actualiza tipo de comida

Basada en v22.3.146. Cuando se cambia manualmente la hora del formulario 'Registrar comida', la categoría pasa automáticamente a desayuno, almuerzo, comida, merienda o cena según las franjas ya definidas.

Franjas: 00:01–10:00 desayuno; 10:01–13:00 almuerzo; 13:01–16:00 comida; 16:01–19:00 merienda; 19:01–00:00 cena.

El usuario sigue pudiendo elegir el tipo manualmente. No hay migraciones ni borrado de datos. La prueba completa en iPhone queda pendiente.
